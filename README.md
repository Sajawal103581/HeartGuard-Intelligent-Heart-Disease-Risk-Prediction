# HeartGuard: Intelligent Heart Disease Risk Prediction

HeartGuard is a machine learning project that estimates a person's risk of heart disease using health data such as age, sex, blood pressure, cholesterol, blood sugar, maximum heart rate and chest pain type. It processes these inputs, looks for patterns linked to heart disease and presents the result in a clear, easy-to-understand form.

> **Medical disclaimer:** HeartGuard is designed to support healthcare decisions, not to replace professional medical diagnosis. Always consult a qualified healthcare provider about your health. If you have chest pain or other urgent symptoms, contact emergency services immediately.

## Features

- Estimates heart disease risk from health data
- Presents results in an easy-to-understand form
- Helps flag possible risk early and encourage medical checkups

## Input Data

| Feature | Description |
|---|---|
| Age | Age in years |
| Sex | Biological sex |
| Blood pressure | Blood pressure reading (mm Hg) |
| Cholesterol | Cholesterol level (mg/dL) |
| Blood sugar | Blood sugar level or category |
| Maximum heart rate | Highest heart rate recorded (bpm) |
| Chest pain type | Category of chest pain |

## How It Works

1. **Input:** Health data is provided.
2. **Preprocessing:** The data is prepared in the format the model expects.
3. **Prediction:** The model estimates the risk of heart disease.
4. **Output:** The result is displayed to the user.
